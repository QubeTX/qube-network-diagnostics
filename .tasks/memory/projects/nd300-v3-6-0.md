# ND-300 v3.6 release

PR #18 is the original release candidate. It hardens macOS repair safety, native Unix update/uninstall, modern diagnostics, Apple signing/notarization, and release provenance. Immutable v3.6.0 and v3.6.1 exposed fail-closed release-verifier defects; v3.6.2 completed the artifact release but its required public Windows updater matrix exposed a running-image defect; v3.6.3 repaired Windows and then exposed a fail-closed current-macOS certificate-argument defect. Final forward-only v3.6.4 is public at exact main `e3bf6c5` with green exact-SHA CI, Windows lifecycle checks, crates.io, tag-bound release verification, 28 assets, Apple trust, public Unix/Windows matrices, and a successful physical Global MSI 3.5.2-to-3.6.4 Alienware update. Evidence PR and cleanup are the remaining closeout gates.

The destructive macOS service-cycle capability remains production-disabled. A public release is allowed and preferred with that gate off.
