# ND-300 v3.6 release

PR #18 is the original release candidate. It hardens macOS repair safety, native Unix update/uninstall, modern diagnostics, Apple signing/notarization, and release provenance. Immutable v3.6.0 and v3.6.1 exposed fail-closed release-verifier defects; v3.6.2 completed the artifact release but its required public Windows updater matrix exposed a running-image defect. The final forward-only version is v3.6.3. It must pass exact-SHA cross-platform CI, Windows installer lifecycle checks, physical Alienware smoke testing, crates.io publication, tag-bound release verification, public update matrices, and evidence closeout.

The destructive macOS service-cycle capability remains production-disabled. A public release is allowed and preferred with that gate off.
